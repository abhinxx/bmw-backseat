# BMW Backseat

Evidence-led product intelligence console for BMW product managers (EHL Hackathon).

Pick a vehicle, propose a feature change, and see how evidence-backed customer segments might react - with every claim traceable to its source. The PM drives; the customers take the backseat.

- Product vision: [BMW_Product_Vision_PRD_Brief.md](BMW_Product_Vision_PRD_Brief.md)

## Status

- Research on the BMW datasets (feedback, customer studies, option lists, sales) done locally.
- Next: cleaned feedback dataset, then the app.
